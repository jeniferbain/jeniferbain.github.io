Diabetes Combination Coding

ICD-10-CM | FY 2027 · A shared guide for CPC and CRC students

1. What is a combination code?

A single ICD-10-CM code may represent diabetes with a specific complication. Multiple diabetes combination codes may be needed when the patient has more than one documented complication.

2. Watch for “with” or “in”

The ICD-10-CM classification presumes a causal relationship for conditions linked by “with” or “in” in the Alphabetic Index or Tabular List, unless documentation clearly states they are unrelated or another guideline requires explicit linkage. Always check the complete entry.

3. Coding example: Type 2 diabetes and CKD stage 3a

A provider documents type 2 diabetes and chronic kidney disease, stage 3a, without indicating they are unrelated.

E11.22Type 2 diabetes mellitus with diabetic chronic kidney disease
+
N18.31Chronic kidney disease, stage 3a

The diabetes combination code identifies CKD associated with diabetes under the classification's “with” convention. An additional N18 code identifies the stage. Review other applicable instructions.

4. Another example: Diabetic polyneuropathy

E11.42Type 2 diabetes mellitus with diabetic polyneuropathy

This combination code includes both diabetes and its specified neurological complication. Don't automatically add another code that merely duplicates the same information.

5. Other key reminders

✓ Multiple diabetes codes may be needed for multiple complications.
✓ Sequencing depends on the reason for the encounter and instructions.
✓ Insulin use alone does not establish diabetes type.
✓ Apply Z79 long-term drug-therapy rules when relevant; temporary insulin does not establish long-term use.

6. Coding workflow

  1. Identify diabetes type and documented complications.
  2. Find Index subterms and “with” relationships.
  3. Confirm codes in the Tabular List.
  4. Follow additional-code instructions.
  5. Verify encounter setting, reportability and sequencing.
