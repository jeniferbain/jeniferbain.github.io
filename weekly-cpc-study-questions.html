Weekly CPC Study Questions

Practice five original questions, choose your answer before opening the rationale, and use the explanation to identify what you should review in your current code books and guidelines.

Week 1 focus: code-book navigation, ICD-10-CM verification, HCPCS Level II, modifiers, and E/M medical decision making. These questions are for education and study practice and are not AAPC exam questions.

1. ICD-10-CM Code Selection

After locating a diagnosis term in the ICD-10-CM Alphabetic Index, what should a coder do before assigning the code?

  1. Report the code directly from the Index
  2. Verify the code in the Tabular List and review applicable instructions
  3. Choose the code with the greatest number of characters
  4. Check the CPT® Index
Answer: B. The Alphabetic Index helps locate a potential code, but code selection must be verified in the Tabular List. Review instructional notes, required characters, laterality, Excludes notes, Code first/Use additional code instructions, and other applicable guidance.

2. HCPCS Level II

Which code set is commonly used to report items and services such as certain supplies, durable medical equipment, and drugs that are not represented by CPT® codes?

  1. ICD-10-CM
  2. HCPCS Level II
  3. ICD-10-PCS
  4. CDT only
Answer: B. HCPCS Level II includes codes for many products, supplies, and services not included in CPT®. CPC students should be comfortable determining which code set is appropriate before searching for a specific code.

3. Modifier Concepts

Why is it important to read the full definition and guidance for a modifier instead of choosing it based only on its short description?

  1. Modifiers always change the diagnosis
  2. Every service requires a modifier
  3. The documentation and circumstances must support the modifier's specific use
  4. Modifiers replace procedure codes
Answer: C. A modifier communicates specific circumstances about a service. The documentation and coding rules must support its use; a familiar-sounding description alone is not enough.

4. E/M Medical Decision Making

For office/outpatient E/M services selected by medical decision making, how many of the three MDM elements generally must meet or exceed a level for that level of MDM to be selected?

  1. One of three
  2. Two of three
  3. All three
  4. None; only time may be used
Answer: B. MDM is based on three elements: problems addressed, data reviewed/analyzed, and risk of patient management. The level is generally determined by meeting or exceeding two of the three elements. Use your current CPT® guidance when working cases.

5. CPC Exam Study Strategy

You miss several practice questions because you know the concept but cannot locate the guideline quickly. What is the best next study step?

  1. Memorize every code number
  2. Stop using the code books during practice
  3. Practice timed code-book navigation and review where the relevant guidelines are located
  4. Only repeat the questions you answered correctly
Answer: C. Efficient navigation is a skill. Timed practice helps you learn where guidelines, notes, tables, appendices, and code sections are located while still reinforcing correct application.

How to use this weekly practice

Answer all five questions without looking at the rationales. Then review every explanation—even the questions you answered correctly. Make a short list of concepts or code-book locations you need to revisit, and practice finding those sections again later in the week.
